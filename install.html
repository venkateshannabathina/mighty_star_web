MightyStar 0.1.1 · Apple Silicon (M1 or later) · macOS 13.5+

  1. Download the DMG, open it, and drag MightyStar into Applications.
  2. Eject the disk and open MightyStar from Applications.
  3. This independent build is locally signed and is not Apple-notarized. If macOS blocks it, first try opening the app, then open System Settings → Privacy & Security → Open Anyway if you trust the download. Keep Gatekeeper enabled.
  4. Choose Get started, scroll to Evelyn, Lynae, Lucy or Rover, and press Enter ↵.
  5. Add a Groq or OpenAI API key once. The app verifies it with that provider and saves it in your Mac’s Keychain.
  6. Your selected companion opens in Overlay mode. Right-click the character for chat, voice, settings and view options.

Internet is required for AI replies and first-use character downloads. English voice resources are included. Extra language packs download on demand. No developer tools or separate Python installation are required.

Your provider may charge for API usage. Chats and memory are stored locally; conversation context is sent to your chosen AI provider when you request a reply. Google account sign-in is not part of v0.1.
